CSS Box Model Analysis & Calculation

Verification of content, padding, border, and margin dimensions for Event Card 1 (#card-hackathon – Hackathon 2026 at SCAD 1st Floor).

Margin: 16px (All Sides)
Border: 1px Solid #334155
Padding: 24px (All Sides)
Content Area Width: 320px • Height: Auto

📐 Total Horizontal Width Calculation

1. Default Content-Box Model (box-sizing: content-box):

Total Width = Content Width + Left Padding + Right Padding + Left Border + Right Border + Left Margin + Right Margin
\[\text{Total Width} = 320 + 24 + 24 + 1 + 1 + 16 + 16 = 398\text{ px}\] (Excluding outer margin: \(320 + 48 + 2 = 370\text{ px}\) rendered on screen)

2. Applied Border-Box Model (box-sizing: border-box):

Specified Width (370px) = Content (320px) + Total Padding (48px) + Total Border (2px)
\[\text{Total Rendered Width} = 370\text{ px} + (16 + 16\text{ Margin}) = 402\text{ px}\] Key Advantage: In border-box, adding padding or borders never blows out grid columns or creates horizontal overflow on mobile screens.
