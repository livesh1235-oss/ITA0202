Exercise 1: Fixing Box-Sizing Overflow

Problem: By default (content-box), adding padding and border to a 100% width element causes it to overflow its parent container boundary.

Parent Container (Width: 340px)
Child Element (width: 100%, padding: 20px, border: 4px)
❌ Defective CSScontent-box
.child { width: 100%; padding: 20px; border: 4px solid red; /* Missing box-sizing: border-box; */ /* Total width = 100% + 40px + 8px (Overflows!) */ }
✅ Corrected CSSborder-box
.child { box-sizing: border-box; width: 100%; padding: 20px; border: 4px solid green; /* Padding & border included inside 100% */ }

Exercise 2: Graceful Exception Handling with try...catch

Problem: Attempting to access nested properties on an undefined object throws an uncaught TypeError, halting script execution.

❌ Unhandled Crash
let student = null; // Throws: TypeError: Cannot read properties of null let gpa = student.academics.cgpa; console.log("GPA: " + gpa);
✅ Defensive try...catch Fix
try { let student = null; let gpa = student?.academics?.cgpa || "N/A"; console.log("Safe GPA: " + gpa); } catch (err) { console.error("Caught Exception: " + err.message); } finally { console.log("Execution cleanly resumed."); }

Exercise 3: Array Off-By-One Logic Error

Problem: Using <= array.length in a for loop accesses an out-of-bounds undefined element on the final iteration, returning NaN.

❌ Off-By-One Loop Bug
const marks = [95, 88, 92, 79]; let sum = 0; // Bug: i <= marks.length accesses marks[4] which is undefined for (let i = 0; i <= marks.length; i++) { sum += marks[i]; } console.log("Sum: " + sum); // Output: NaN
✅ Corrected Boundary Condition
const marks = [95, 88, 92, 79]; let sum = 0; // Fixed: i < marks.length for (let i = 0; i < marks.length; i++) { sum += marks[i]; } console.log("Correct Total Sum: " + sum); // Output: 354
