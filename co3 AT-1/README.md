# CO3 &ndash; Assessment 1 &ndash; Experiments

This folder contains the complete implementation for **CO3 Assessment 1**, consisting of:
1. **Experiment Question 1**: DOM-Based Interactive Student Registration Preview
2. **Experiment Question 2**: Servlet-Based Student Result Processing

---

## 📑 Contents

| Component | Path | Description |
| :--- | :--- | :--- |
| **Central Dashboard** | [`index.html`](index.html) | Central portal to navigate and launch experiments. |
| **Full Solutions & Theory** | [`ASSESSMENT_SOLUTIONS.md`](ASSESSMENT_SOLUTIONS.md) | In-depth answers, algorithms, code snippets, and explanations. |
| **Question 1 (DOM Preview)** | [`q1_dom_profile_preview/`](q1_dom_profile_preview/) | Interactive DOM profile generator with Display & Remove actions. |
| **Question 2 (Servlet Result)** | [`q2_servlet_result_processing/`](q2_servlet_result_processing/) | Java Servlet (`StudentResultServlet.java`), HTML form, and Maven WAR build. |
| **Screenshots** | [`screenshots/`](screenshots/) | Output screenshots folder. |

---

## 🎯 Quick Start

* **To test Question 1 (Client-side DOM)**: Open [`q1_dom_profile_preview/index.html`](q1_dom_profile_preview/index.html) in any browser.
* **To inspect Question 2 (Java Servlet)**: Open [`q2_servlet_result_processing/src/main/java/com/co3/assessment/StudentResultServlet.java`](q2_servlet_result_processing/src/main/java/com/co3/assessment/StudentResultServlet.java).
