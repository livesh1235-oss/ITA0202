Student Marks Result Processing

Submits student details & 3 subject marks via HTTP POST to StudentResultServlet (/processResult) for server-side processing.

1. Student Information
2. Subject Marks (Range: 0 to 100 • Pass ≥ 50)
Server Concurrency Compliance: The servlet computes Total, Average, Highest Mark, and Pass/Fail status using private stack local variables, ensuring thread-safe processing during concurrent student submissions.
