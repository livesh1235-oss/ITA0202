📚 Intrinsic vs addEventListener() Comparison

Feature Intrinsic (Inline HTML) Modern addEventListener
Syntax <button onclick="fn()"> btn.addEventListener('click', fn)
Multiple Handlers ❌ Overwrites previous handler ✅ Multiple independent listeners
Separation of Concerns ❌ Mixes HTML and JavaScript ✅ Clean HTML/JS decoupling
Event Phase Control ❌ Bubbling only ✅ Supports Bubbling & Capturing
Dynamic Removal Harder (setting to null) ✅ removeEventListener()
