3. CSS @supports Feature Query Demonstration

The card below uses CSS @supports (backdrop-filter: blur(10px)) to apply a modern frosted glass aesthetic if supported, falling back gracefully to solid opaque background styling on older browsers.

Frosted Glass Component

If modern CSS is supported, this box renders with backdrop blur and semi-transparent alpha glassmorphism. On noncompliant browsers, it degrades gracefully to a clean solid border card.
