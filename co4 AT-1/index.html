Question 1

Interpret the XML Structure 5 Marks

a. Identify the root element.
Root Element: <courses> — The top-level document element containing all course entities.
b. Identify the repeating record element.
Repeating Element: <course> — Represents individual course record instances (C101 through C105).
c. Identify the attribute used to uniquely identify each course.
Attribute: id (e.g. id="C101", id="C102", id="C103", id="C104", id="C105").
d. Identify the elements that represent numeric information.
Numeric Elements: <students> (enrollment count) and <credits> (academic credit count).
e. State whether the XML document is structurally well-formed and justify your answer.
Yes, the XML document is structurally well-formed.
  • It contains a single unique root element (<courses>).
  • Every opening element has a matching, strictly closed closing tag (e.g., <name>...</name>).
  • Elements are properly nested in strict LIFO order without overlapping.
  • All attribute values are enclosed in quotes (e.g. id="C101").
  • Contains a valid XML prolog: <?xml version="1.0" encoding="UTF-8"?>.

Question 3

Apply XSLT for Data Presentation 10 Marks

XSLT transformation (courses.xsl) filtering courses with students > 40 and sorting descending by student enrollment:

<?xml version="1.0" encoding="UTF-8"?>
<xsl:stylesheet version="1.0" xmlns:xsl="http://www.w3.org/1999/XSL/Transform">
    <xsl:output method="html" doctype-system="about:blank" indent="yes" encoding="UTF-8"/>

    <xsl:template match="/">
        <html>
        <head>
            <title>High Enrollment Courses</title>
        </head>
        <body>
            <h2>High Enrollment Courses</h2>
            <table border="1">
                <tr bgcolor="#1e293b" style="color: white;">
                    <th>Course Code</th>
                    <th>Course Name</th>
                    <th>Faculty</th>
                    <th>Students</th>
                    <th>Credits</th>
                    <th>Type</th>
                </tr>
                <!-- Filter condition: students > 40 -->
                <xsl:for-each select="/courses/course[students > 40]">
                    <!-- Sorting: descending order of student count -->
                    <xsl:sort select="students" data-type="number" order="descending"/>
                    <tr>
                        <td><xsl:value-of select="code"/></td>
                        <td><xsl:value-of select="name"/></td>
                        <td><xsl:value-of select="faculty"/></td>
                        <td><xsl:value-of select="students"/></td>
                        <td><xsl:value-of select="credits"/></td>
                        <td><xsl:value-of select="type"/></td>
                    </tr>
                </xsl:for-each>
            </table>
        </body>
        </html>
    </xsl:template>
</xsl:stylesheet>
