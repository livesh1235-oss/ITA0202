Experiment 03

Creating a Class Timetable Using HTML Tables

Objective: Construct an academic class timetable implementing HTML <table>, table rows (<tr>), table headers (<th>), data cells (<td>), <caption>, row merging (rowspan), column merging (colspan), along with border, cellpadding, and cellspacing attributes.

HTML Table Tags & Attributes Used:

  • <table border="1" cellpadding="10" cellspacing="0">: Defines the table with border width, internal cell padding, and cell spacing.
  • <caption>: Provides an accessible, prominent title for the timetable.
  • <th> and <tr>: Define table headers and table rows.
  • rowspan="5": Merged the Tea Break and Lunch columns across all 5 weekdays (Monday to Friday).
  • colspan="3": Merged 3 laboratory periods in the afternoon session for seamless practical lab representation.
