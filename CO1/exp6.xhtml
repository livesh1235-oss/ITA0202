Experiment 06

Creating an XHTML-Compliant Web Page

Objective: Author an XML-compliant, strictly validated XHTML 1.0 document adhering to all syntactic rules: lowercase elements, explicit tag closures, quoted attribute values, rigorous nesting hierarchy, and self-closing empty elements.

✔ W3C XHTML 1.0 Strict Validated Syntax

1. DOCTYPE and XML Namespace (xmlns)

Every XHTML document must begin with an XML prologue and an explicit DOCTYPE declaration referencing the W3C DTD, along with the standard xmlns="http://www.w3.org/1999/xhtml" attribute in the root <html> element.

2. All Tags and Attributes in Lowercase

Because XML is case-sensitive, all XHTML tags and attribute names must strictly be written in lowercase (e.g. <table>, <tr>, <td>, <p>, class="...").

3. Mandatory Tag Closure

Non-empty elements must have matching closing tags (e.g. <p>...</p>, <li>...</li>). No tag closure can be omitted.

4. Self-Closing Empty Elements

Empty tags without inner content must be closed with a trailing space and forward slash: <br />, <hr />, <img src="..." alt="..." />, and <input type="..." />.

5. All Attribute Values Must Be Quoted & Attribute Minimization Prohibited

Attribute values must always be enclosed within double quotes. Minimized attributes (e.g. checked, disabled) must be written in full: checked="checked", disabled="disabled".

XHTML Strict vs. Legacy HTML Comparison

Syntactic Rule Incorrect (Legacy HTML) Correct (XHTML Strict Compliant)
Tag Case <DIV><P>text</P></DIV> <div><p>text</p></div>
Empty Tags <br>, <hr>, <img src="pic.jpg"> <br />, <hr />, <img src="pic.jpg" alt="pic" />
Attribute Quotes <table width=100% border=1> <table style="width:100%" border="1">
Attribute Minimization <input type="checkbox" checked> <input type="checkbox" checked="checked" />
Proper Nesting <b><i>Sample</b></i> <b><i>Sample</i></b>
