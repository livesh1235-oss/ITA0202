Experiment 01

Creating a Basic HTML Web Page

Objective: Demonstrate the use of basic HTML formatting tags including all 6 heading levels, paragraphs, line breaks, horizontal rules, text formatting (bold, italic, underline), superscripts, and subscripts.

1. Demonstration of Heading Tags (<h1> to <h6>)

HTML provides 6 levels of document headings. <h1> is the most important, and <h6> is the least important.

Heading Level 1 - <h1> Main Document Title

Heading Level 2 - <h2> Major Section Heading

Heading Level 3 - <h3> Subsection Heading

Heading Level 4 - <h4> Topic Heading

Heading Level 5 - <h5> Minor Subtopic Heading
Heading Level 6 - <h6> Lowest Level Heading

2. Paragraphs (<p>), Line Breaks (<br>), and Horizontal Rules (<hr>)

Paragraphs define blocks of text. The line break tag creates a single line feed without starting a new paragraph. The horizontal rule inserts a thematic break.

4. Superscripts (<sup>) and Subscripts (<sub>)

Superscript renders text half a character above the normal line (useful for exponents and ordinal numbers). Subscript renders text half a character below (useful for chemical formulas and mathematical indices).

Mathematical Equations (Using <sup>):

Pythagorean Theorem: a2 + b2 = c2
Quadratic Form: f(x) = ax3 + bx2 + cx + d
Ordinal Date: The submission deadline is the 25th of August.

Sulfuric Acid: H2SO4
Glucose: C6H12O6

Vector Components: V = (x1, x2, x3, ..., xn)
