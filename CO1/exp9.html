Experiment 09

Observing Internet Protocols Using Browser Developer Tools

Objective: Utilize the browser's Developer Tools (F12) → Network Tab to observe real HTTP/HTTPS network traffic, analyzing URL, Protocol (HTTP/1.1, HTTP/2), Request Method, Status Code, MIME Type, Payload Size, and Waterfall Loading Times.

How to Observe Network Traffic in Developer Tools:

1 Press F12 (or Ctrl + Shift + I / Cmd + Option + I on Mac) to open Developer Tools.

2 Switch to the "Network" tab.

3 Check the "Preserve log" box and select "All" or "Fetch/XHR" filter.

4 Click any of the interactive trigger buttons below to generate real HTTP requests and observe them live in your Network panel!

Key Network Attributes Explained:

  • Protocol: The transport standard in use (e.g. http/1.1, h2 for HTTP/2 multiplexing, or h3 for HTTP/3 over QUIC).
  • Status Code: 3-digit HTTP response code (200 OK = Success, 304 = Cached, 404 = Not Found, 500 = Server Error).
  • MIME Type: The payload format indicated via the Content-Type header (e.g., text/html, text/xml, application/json).
  • Waterfall: Breakdown of time spent in DNS Lookup, Initial Connection, SSL Handshake, Waiting (TTFB - Time to First Byte), and Content Download.
